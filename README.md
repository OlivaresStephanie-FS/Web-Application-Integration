# 💻 Web Application Integration | WDV4416

**Full Sail University | October 2026**

This repository contains my assignments for Web Application Integration. The course focuses on testing, integrating, and improving web applications using different testing methods and tools.

## 📁 Assignments

### Module 1 – Unit Testing

Created a JavaScript function that obscures credit card numbers while keeping the last four characters visible. Used Jest to write and run unit tests following the Test-Driven Development (TDD) approach.

- Accepts strings between 12 and 16 characters.
- Returns "Invalid Credit Card" for invalid lengths.
- Includes positive and negative tests.
- All 6 unit tests passed.

### Module 2 – Integration Testing

Used Postman to test GET, POST, PATCH, and DELETE routes from a provided backend.

- Tested status codes, response messages, payload data, and metadata.
- Saved all requests in one Postman collection.
- All 15 integration tests passed.

### Module 2 – Selenium Testing

Used Selenium WebDriver to automate browser testing on a provided Next.js application.

- Verified the Home page title.
- Verified the Contact Us page title.
- Tested the email signup interaction and response message.
- All 3 Selenium tests passed.
